## Открытые вопросы

- Предложения 0008-0012 ждут решения владельца.
- UI-06 и NFR-03 (масштаб 150%) расходятся с 0004; требования не менялись.
- LAY-06: именованных пользовательских раскладок нет (0002).

## Порядок реализации

Каждый шаг - отдельный коммит со своей проверкой.

1. `cmake/pdklib.cmake` (0007). Проверка: сборки `build`, `build-dev`, `pdk/tools`.
2. Копия ImGui в `third_party/imgui/` и иконок win-55-ui (0001, 0003). Проверка: `sha256sum -c` по
   `ORIGIN.md`.
3. CMake редактора: `sdl.cmake`, `pdklib.cmake`, библиотека `3dmppc_editor_imgui`; окно SDL3 с пустым
   кадром ImGui. Проверка: сборки `editor/build`, `build-dev`, `build`; ручной запуск окна.
4. Токены темы и перенос в `ImGuiStyle`. Проверка: сборка; файл токенов не включает `imgui.h`.
5. Шрифт редактора без сглаживания (0004). Проверка: сборка; скриншот текста.
6. Примитивы и первые виджеты, каркас Widget Catalog. Проверка: сборка; скриншот каталога.
7. Модель дерева тайлов без ImGui. Проверка: сборка; модель не включает заголовки ImGui.
8. Отрисовка дерева: разделители, вкладки, перенос, разворачивание. Проверка: ручной сценарий AC-07.
9. Сохранение раскладки, стартовые раскладки, сброс и восстановление. Проверка: запуск с испорченным
   файлом даёт стартовую раскладку.

Шаги 4-6 и 7 не зависят друг от друга; шаг 8 требует обоих. Шаги 1-9 выполнены; следующие -
клиент nvim (0005) и кадр Game (0006).

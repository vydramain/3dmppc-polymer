# Архитектурные решения 3dmppc-editor

Решения, которые требования (`../3dmppc-editor-v0.4-requirements.md`) оставляют на ADR. Каждый
файл - одно решение: контекст, решение, последствия.

| Файл | Решение | Статус |
| --- | --- | --- |
| [0001-ui-toolkit.md](0001-ui-toolkit.md) | Dear ImGui `v1.92.9b`, SDL3 и SDL_Renderer, копия в `third_party/` | принято |
| [0002-tiling.md](0002-tiling.md) | своё дерево раскладки, доли, минимумы от панелей | принято |
| [0003-theme-and-components.md](0003-theme-and-components.md) | токены, примитивы, виджеты; иконки из win-55-ui | принято |
| [0004-fonts.md](0004-fonts.md) | редактор - PxPlus IBM VGA 9x16, масштаб только `--scale`; кириллица дисков - блок `rv_font` | принято |
| [0005-code-editor-nvim.md](0005-code-editor-nvim.md) | минимальный клиент `nvim --embed` | принято |
| [0006-game-frame.md](0006-game-frame.md) | кадр рисует консоль, редактор показывает | транспорт открыт |
| [0007-pdklib-cmake.md](0007-pdklib-cmake.md) | общий `cmake/pdklib.cmake` | принято |

Имена типов и функций редактора начинаются с `rv_editor_`.

## Открытые вопросы

- Транспорт кадра и ввода Game (0006, GAM-02).
- Правка требований: раздел 10 под nvim и противоречие с ARC-05 (0005).

## Порядок реализации

Каждый шаг - отдельный коммит со своей проверкой.

1. `cmake/pdklib.cmake` (0007). Проверка: сборки `build`, `build-dev`, `pdk/tools`.
2. Копия ImGui в `third_party/imgui/` и иконок win-55-ui (0001, 0003). Проверка: `sha256sum -c` по
   `ORIGIN.md`.
3. CMake редактора: `sdl.cmake`, `pdklib.cmake`, библиотека `3dmppc_editor_imgui`; окно SDL3 с пустым
   кадром ImGui. Проверка: сборки `editor/build`, `build-dev`, `build`; ручной запуск окна.
4. Токены темы и перенос в `ImGuiStyle`. Проверка: сборка; файл токенов не включает `imgui.h`.
5. Шрифт редактора без сглаживания (0004). Проверка: сборка; скриншот текста.
6. Примитивы и первые виджеты, каркас Widget Catalog. Проверка: сборка; скриншот каталога.
7. Модель дерева тайлов без ImGui. Проверка: сборка; модель не включает заголовки ImGui.
8. Отрисовка дерева: разделители, вкладки, перенос, разворачивание. Проверка: ручной сценарий AC-07.
9. Сохранение раскладки, стартовые раскладки, сброс и восстановление. Проверка: запуск с испорченным
   файлом даёт стартовую раскладку.

Шаги 4-6 и 7 не зависят друг от друга; шаг 8 требует обоих. Клиент nvim (0005) и кадр Game (0006)
идут после этого блока.

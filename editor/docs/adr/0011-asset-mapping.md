# 0011. Соответствие исходников и записей диска

Статус: принято 2026-09-25. Относится к RLD-02, RLD-06, ARC-04, BLD-06.

## Контекст

Имя записи на диске знает только burner: `assets/example-sprite.png` становится
`example-sprite.mppctex`, скрипт - записью по имени файла без каталога
(`pdk/tools/mppcburner/rv_burner_assets/rv_burner_plan.cpp`). Запрос `asset example-sprite` отвечает
`no_asset`; работает только `asset example-sprite.mppctex` (проверено на dev-консоли). Редактор не
должен повторять правила именования у себя (RLD-02).

## Решение

- `mppcburner build` пишет карту рядом с результатом: `--map PATH`, по строке на запись:
  `<исходник относительно root> <kind> <имя записи> [<параметры>]`, где kind - `entry`, `module`,
  `texture`, `sound`, `file`, `code`; для `module` - имя для `require`, для `texture` - формат
  (`idx8`, ...), тот же, что burner передал baker.
- Редактор читает карту после каждой успешной сборки и по ней выбирает действие reload: `reload
  entry`, `reload module <имя>`, `asset <имя записи>` или Restart required.
- Пересборка одной текстуры: baker с параметрами из карты пишет результат во временный файл рядом
  с записью в unpacked-каталоге; успех - rename поверх записи, затем `asset`. Ошибка baker - запись
  не трогается, `asset` не посылается (RLD-06).
- Карта - часть результата сборки: неуспешная сборка карту не заменяет.

## Последствия

- Burner получает опцию `--map`; формат карты версионируется первой строкой.
- Редактор не содержит правил именования записей.

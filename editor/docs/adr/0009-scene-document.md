# 0009. Документ сцены и его загрузчик

Статус: принято 2026-09-25. Относится к SCN-01..SCN-10, TPL-05.

## Контекст

В PDK и pdklib сцены нет: `pdk/lib/README.md` прямо не даёт scene graph. `disc.toml` разбирает
pdklib (`rv_manifest`: лексер, парсер, семантика), но схема разборщика знает только секции
манифеста. SCN-02 требует формат и загрузчик, доступные проекту без редактора, и запрещает новый
язык ради UI.

## Решение

- Файл сцены - текст в том же диалекте, что `disc.toml`: `scenes/<имя>.scene.toml`.
  ```toml
  [scene]
  format = 1

  [[object]]
  id = "5f3a9c10"          # стабильный, выдаёт редактор, не меняется при переименовании
  name = "camera"
  parent = ""              # id родителя или пусто
  kind = "camera"          # group | camera | mesh
  position = [0, 1.5, -4]
  rotation = [0, 0, 0]     # градусы, порядок Y, X, Z
  scale = [1, 1, 1]
  mesh = ""                # имя ассета диска для kind = mesh
  texture = ""
  ```
- Загрузчик - `pdklib/rv_scene`: читает файл с диска через drive, отдаёт массив объектов с
  разрешёнными родителями. Он дисковый, как `rv_font`: редактор его не линкует, игра использует его
  или нет.
- Burner копирует `scenes/*.scene.toml` на диск как обычные ассеты (секция `[scenes]` манифеста).
- Transform локальный относительно родителя. Циклы родителей и неизвестный `id` - ошибка загрузки.
- Незнакомые ключи объекта редактор сохраняет как есть (SCN-06). `format` выше известного -
  сцена открывается только для чтения.
- Изменение сцены во время Run - Save, Build, Restart (раздел 9 требований), пока нет scene reload.

## Последствия

- Разборщик `rv_manifest` делится на общий диалект и схему манифеста, чтобы вторая схема не
  копировала лексер.
- Оба стартовых диска получают по сцене с камерой и одним объектом (TPL-05).
- solid-maid сцен не получает автоматически (TPL-06).

# 0002. Тайловое рабочее пространство: своё дерево раскладки

Статус: принято. Закрывает LAY-01..LAY-09 на уровне архитектуры.

## Контекст

Ветка `docking` Dear ImGui даёт готовый DockSpace, но в `v1.92.9b-docking` размеры узлов
сохраняются в `imgui.ini` в пикселях (`SizeRef=%d,%d`, `Size=%d,%d`), временного разворачивания
тайла нет, а вкладки и заголовки рисует сама ImGui. LAY-02 требует отношений, LAY-01 -
разворачивания, UI-02 - скошенных вкладок и stippled-заголовков.

## Решение

Своё дерево раскладки поверх ImGui `master`.

```cpp
struct rv_editor_tile_split { rv_editor_axis axis; float ratio; uint32_t first, second; };
struct rv_editor_tile_leaf  { std::vector<rv_editor_pane_id> tabs; uint32_t active; };
// узел - split или leaf; у раскладки ещё maximized_leaf
```

- Раскладка - только представление. Панель - вид на модель (runtime session, build job, документы),
  модель живёт вне UI. Закрытие тайла не останавливает runtime и не отменяет сборку (LAY-09);
  несколько Output или code-панелей не создают процессов (LAY-08).
- Панели хранятся в отдельном реестре `rv_editor_pane_id -> вид панели + её состояние`.
- Операции над деревом - чистые функции без ImGui: split, merge-to-tabs, move, close, maximize,
  clamp по минимальным размерам.
- Размеры хранятся долями (`ratio`), не пикселями (LAY-02).
- Минимальный размер задаёт сама панель, дерево его только применяет:

  ```cpp
  struct rv_editor_size { int32_t w, h; };
  // у каждой панели: rv_editor_size min_size() const;
  ```

  Game: размер кадра, который сообщает консоль, умноженный на целый масштаб (>= 1), плюс рамка
  тайла. До первого кадра - только рамка и явная пометка "размер неизвестен" (LAY-03). Остальные
  панели - по своим текстам и контролам (LAY-04). Ограничение пересчитывается при каждом изменении
  минимума, а не только при изменении окна.
- Fit - отдельный, явно обозначенный режим Game; на минимум он не влияет (LAY-05).
- Отрисовка: разделители и полосы вкладок - виджеты редактора (0003); перенос вкладок - через
  `BeginDragDropSource/Target` ImGui.
- Сохранение - свой текстовый файл. Стартовые раскладки Scene, Code + Game, Debug/Output (LAY-07) -
  заранее построенные деревья. Файл, который не разобрался, заменяется стартовой раскладкой без
  потери документов (LAY-06).

## Последствия

- Превью места падения вкладки при переносе пишется самостоятельно.
- Модель дерева не включает заголовки ImGui; это проверяется по include.

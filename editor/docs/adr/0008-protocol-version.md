# 0008. Версия dev-протокола и возможности сессии

Статус: предложение, ждёт решения владельца. Относится к DEV-02, NFR-06, AC-17.

## Контекст

`status` отвечает `protocol=1` и сообщает `medium=live|fixed` и `entry_reloadable=0|1`
(`src/rv_pconsole/rv_pconsole_cmd_devtools.cpp`). Согласования возможностей в протоколе нет. У
`mppcburner` и `mppcbaker` нет опции версии. Player-сборка `--dev` не знает и завершается с кодом 2.

## Предложение

- Версия протокола - одно целое число. Редактор знает список поддержанных версий и работает только с
  ними; другая версия - понятная ошибка, команды сессии заблокированы, документы доступны.
- Возможности не согласуются, а выводятся: из версии (какие команды есть) и из `status` (носитель,
  перезагружаемость entry). Кнопка, которую текущая сессия не поддерживает, отключена с причиной.
- Изменение формы ответа или новая команда повышает версию. Кадр и ввод Game (0006) - версия 2.
- Проверка при старте сессии: процесс запущен, первый запрос - `status`; нет ответа за таймаут или
  код 2 при запуске - это не dev-сборка, сессия не открывается.
- Инструменты получают `--version` с одной строкой `<имя> <версия>`; редактор показывает её в
  диагностике (NFR-06) и перечитывает после смены пути к файлу.

## Последствия

- Консоль и инструменты меняются: версия протокола 2 и `--version`.
- Старый редактор с новой консолью честно отказывается работать, а не угадывает.

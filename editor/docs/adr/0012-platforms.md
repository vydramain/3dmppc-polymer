# 0012. Платформы редактора

Статус: предложение, ждёт решения владельца. Относится к NFR-01.

## Контекст

Редактор запускает процессы (консоль, burner, nvim), создаёт PTY для терминала, разделяемую память
для кадра Game (0006) и следит за файлами проекта. Всё это зависит от ОС.

## Предложение

| Платформа | Статус v0.4 | Проверка |
| --- | --- | --- |
| Linux, X11 | поддерживается | все AC |
| Linux, Wayland | поддерживается | все AC, отдельно AC-10 и AC-11 |
| Windows, macOS | не объявляются | - |

- Платформенный код лежит в одном каталоге редактора за четырьмя интерфейсами: запуск процесса
  (argv, cwd, environment, свои pipe; `posix_spawn`), PTY (`openpty`), разделяемая память
  (`memfd_create`) и наблюдение за файлами (`inotify`). Остальной редактор этих вызовов не видит.
- Другая платформа объявляется только после того, как на ней проходят те же AC.

## Последствия

- Первая реализация - только Linux; адаптеры других ОС пишутся, когда платформа нужна.

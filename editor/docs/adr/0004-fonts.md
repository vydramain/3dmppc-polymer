# 0004. Шрифты

Статус: принято, кроме раскладки кириллицы (см. "Открыто").

## Контекст

В pdklib уже есть растровый шрифт `pdk/lib/include/pdklib/rv_font/rv_font_data.hpp`: чернила 5x7 в
клетке 8x8, 8 байт на глиф, ASCII 32..126 и заглушка notdef. Консоль его не рисует сама: диск
загружает атлас как обычную текстуру (`rv_font.hpp`), а пауза консоли растеризует те же биты прямо в
ARGB-буфер (`src/rv_pconsole/rv_pcpause_overlay.cpp`).

Сейчас атлас - 16x6 клеток, 128x48 IDX4, 3072 байта (`rv_font_texture.hpp`), а разметка текста
перебирает байты, не символы UTF-8 (`rv_font.hpp`, `for (const char c : text)`).

## Решение

- Шрифт редактора - `rv_font` из pdklib. Данные глифов существуют в одном экземпляре (ARC-03);
  редактор подключает заголовки pdklib, кода консоли из `src/` не видит.
- Глифы отдаются ImGui своим загрузчиком `ImFontLoader` (интерфейс ImGui 1.92). Загрузчик
  увеличивает глиф повтором пикселей до нужного целого размера, так что пиксель атласа ложится ровно
  на пиксель экрана.
- Никакого сглаживания (0001). Масштабы интерфейса - целые.
- Кириллица добавляется в таблицу pdklib.
- Лицензированный TTF как запасной шрифт пока не подключается: символ вне таблицы рисуется
  заглушкой notdef.
- Шрифты из win-55-ui не используются ни в каком виде (0003).

## Открыто

Как добавить кириллицу, не заставив каждый диск платить за неё:

- блоки глифов (ASCII, кириллица, позже стрелки и символы рамок) и сборка атласа из выбранных блоков;
  диск только с ASCII остаётся с атласом в 3072 байта;
- одна расширенная таблица: 162 глифа, атлас 128x88, 5632 байта у каждого диска.

В обоих случаях разметка текста переходит с байтов на символы UTF-8; поведение
`rv_font_measure_width` и отрисовки для существующих дисков меняется.

## Последствия

- UI-06 требует отдельных шрифтов для интерфейса и моноширинного текста; пока оба - `rv_font`.
- Растр 8x8 масштабируется только в целое число раз; масштаб 150% (NFR-03) округляется.

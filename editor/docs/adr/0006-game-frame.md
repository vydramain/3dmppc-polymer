# 0006. Кадр Game: рисует консоль, показывает редактор

Статус: принято в части ответственности; транспорт кадра открыт (GAM-02).

## Решение

- Пиксели игры производит только консоль: она растеризует кадр в общий буфер. Редактор ничего не
  пересчитывает и не копирует симуляцию (GAM-01).
- Редактор выводит готовый кадр одной `SDL_Texture` с `SDL_SCALEMODE_NEAREST` в прямоугольник
  тайла, целым масштабом по умолчанию, Fit - явным режимом (LAY-05).
- Размер кадра динамический и задаётся консолью: он приходит в заголовке каждого кадра вместе со
  stride, форматом и номером кадра (GAM-03). Смена режима консоли меняет размер со следующего кадра.
- Минимальный размер тайла Game выводится из этого размера (0002).

## Факт

Ответ `status` dev-протокола сейчас размера кадра не содержит (поля `protocol`, `frame`, `mode`,
`medium`, `disc`, ...). Ширину и высоту протокол отдаёт только для текстуры в ответе `asset`
(`src/rv_pconsole/rv_pconsole_cmd_devtools.cpp`). Размер кадра - часть нового контракта кадра.

## Открыто

Транспорт кадра и ввода: shared memory или другой переносимый механизм (GAM-02). Встраивание чужого
окна не гарантирует работу под Wayland и не выбирается.

# 0006. Кадр и ввод Game: разделяемая память и dev-протокол

Статус: принято. Закрывает GAM-02.

## Контекст

Консоль - отдельный процесс (DEV-01). Ответ `status` dev-протокола размера кадра не содержит (поля
`protocol`, `frame`, `mode`, `medium`, `disc`, ...); ширину и высоту протокол отдаёт только для
текстуры в ответе `asset` (`src/rv_pconsole/rv_pconsole_cmd_devtools.cpp`). Кадр 320x240 ARGB - 300 КиБ;
60 таких кадров в секунду через pipe протокола заняли бы канал команд. Встраивание чужого окна не
гарантирует работу под Wayland и не выбирается.

## Решение

- Пиксели игры производит только консоль. Редактор ничего не пересчитывает и не копирует симуляцию
  (GAM-01).
- Кадр лежит в разделяемой памяти. Редактор создаёт объект памяти (`memfd_create` на Linux) и
  передаёт дескриптор консоли при запуске опцией `--frame-fd N`. Опция есть только в
  dev-сборке (GAM-07). С ней консоль окна не открывает; звук выводит она сама, редактор звука не
  имеет (GAM-04).
- Память: заголовок (magic, версия, число слотов, размер слота) и три слота. Слот: счётчик записи,
  номер кадра, ширина, высота, stride, формат (ARGB8888), пиксели. Консоль пишет в слот, который
  не объявлен последним; счётчик нечётный, пока слот пишется. Редактор копирует объявленный слот в
  текстуру и сверяет счётчик до и после копии: изменился - кадр пропускается. Консоль редактора не
  ждёт никогда (GAM-03).
- Через протокол идёт только номер кадра: событие `0 frame frame=<n> slot=<k>`. Размер кадра
  берётся из слота, поэтому смена режима консоли меняет размер со следующего кадра.
- Ввод: команда протокола `pad <port> <buttons-hex>` при каждом изменении. Редактор шлёт её, только
  пока тайл Game в фокусе и сессия не на паузе. Потеря фокуса, пауза и `Shift+Esc` посылают `pad` со
  всеми отпущенными кнопками; `Shift+Esc` игре не передаётся (GAM-04, GAM-05).
- На паузе в слоте остаётся последний кадр; тайл показывает его с пометкой паузы (GAM-06).
- Редактор выводит кадр одной `SDL_Texture` с `SDL_SCALEMODE_NEAREST` в прямоугольник тайла, целым
  масштабом по умолчанию, Fit - явным режимом (LAY-05). Минимальный размер тайла Game выводится из
  размера кадра (0002).
- Событие `frame`, команда `pad` и опция `--frame-fd` - новая версия протокола, `protocol=2` (0008).

## Последствия

- Консоли нужна dev-платформа без окна, которая пишет кадр в память и берёт ввод из протокола.
  Player-сборка её не содержит.
- Runtime Controls и инспектор работают на командах, которые протокол уже имеет: `pause`,
  `resume`, `step`, `reload`, `asset`, `get`, `keys`, `gc`, `quit`.
- Windows и macOS создают и передают память по-своему; это платформенный адаптер (0012).

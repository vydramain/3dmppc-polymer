# Иконки редактора: сетка

Список мест, где редактору нужна иконка, и что каждая означает. Пока иконок нет, на их месте стоит
цветная буква: она занимает место будущей иконки, так что раскладка не изменится, когда иконки
появятся. Решение владельца 2026-09-25: сначала сетка с контекстом, потом рисование.

В дереве файлов строка высотой в одну клетку шрифта (8x8 при `--scale 1`), и там стоит сама буква
своего цвета. На кнопках транспорта место под иконку 16x16, и там буква лежит на плашке своего
цвета: тёмная на светлом, светлая на тёмном. Цвета - из палитры редактора и Catppuccin Mocha, чтобы
не спорить с оливковым хромом.

## Транспорт (Runtime Controls, меню Run)

Шесть кнопок транспорта рисуют картинку 8x8 пикселей (`rv_editor_draw_glyph`), остальные - буквы.

| Контекст | Смысл | Картинка / буква | Цвет | Состояния |
| --- | --- | --- | --- | --- |
| Build | собрать диск burner'ом | молоток | `#fab387` | доступна, выключена, идёт сборка |
| Run / Resume | запустить последнюю сборку, снять паузу | треугольник | `#a6e3a1` | доступна, выключена |
| Pause | остановить на границе кадра | две полосы | `#f9e2af` | доступна, выключена, ожидание |
| Step | один кадр на паузе | треугольник у черты | `#89b4fa` | доступна, выключена, ожидание |
| Stop | `quit` и ожидание | квадрат | `#f38ba8` | доступна, выключена, ожидание |
| Reload | горячая перезагрузка | стрелка по кругу | `#cba6f7` | доступна, выключена |
| Force Stop | убить зависшую консоль | `K` | `#f38ba8` | - |
| Cancel Build | отменить сборку | `C` | `#fab387` | - |
